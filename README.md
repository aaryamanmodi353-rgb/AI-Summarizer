A lightweight, powerful browser extension that uses Large Language Models to instantly summarize the content of any web page or article you are currently reading. Say goodbye to long reads and extract the core insights in seconds directly from your browser toolbar.

## ✨ Features

- **One-Click Summarization**: Click the extension icon to instantly generate a summary of the active tab's content.
- **Context-Aware Extraction**: Automatically identifies and extracts the main article text, ignoring navbars, ads, and footers.
- **Modern Popup UI**: Clean, responsive, and intuitive interface built with HTML/CSS.
- **Copy to Clipboard**: Easily copy the generated summary for use in notes or reports.
- **Manifest V3 Compliant**: Built using the latest, most secure, and performant extension architecture.

## 🛠️ Tech Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript
- **Extension API:** Chrome Extension API (Manifest V3)
- **AI Integration:** Google Gemini API / Groq SDK (or your chosen provider)
- **DOM Parsing:** Readability.js (or custom content scripts for text extraction)
